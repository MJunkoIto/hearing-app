# Webサイト制作ヒアリングシート

## アプリ概要

Webサイト制作前に、クライアント様から必要な情報をうかがうための「ヒアリングシート」アプリです。
1画面に必要な質問項目をまとめて表示し、回答内容をブラウザの localStorage に保存します。
送信ボタンを押すと回答を一覧で確認でき、その後の編集・削除も可能です。

## 誰のどんな問題を解決するか

**対象ユーザー：フリーランスのWeb制作者**

クライアント様にWebサイト制作前の質問へ回答してもらうとき、
メール・チャット・口頭などで質問と回答が散らばってしまい、整理しづらいことがあります。

本アプリは、Webサイト制作に必要な質問項目を1画面にまとめ、
回答を1か所に保存・確認できるようにすることで、ヒアリング情報の散らばりを解消します。

## 主な機能

- 8つの質問項目への回答入力
- 回答内容を localStorage に自動保存（ページを更新しても残る）
- 「送信する」ボタンで入力内容を一覧表示
- 「編集する」ボタンで入力画面に戻り、内容を修正できる
- 「すべて削除」ボタンで入力内容と保存データをまとめて削除
- スマートフォンでも見やすいレスポンシブ対応

## 使い方

1. アプリを開く（GitHub Pages の公開URLまたはローカル）
2. 各質問のテキストエリアに回答を入力する
   - 入力中の内容は自動で localStorage に保存されます
3. すべて入力したら一番下の「**送信する**」ボタンを押す
4. 入力した回答が一覧で表示されます
5. 修正したい場合は「**編集する**」を押すと入力画面に戻ります
6. 内容をリセットしたい場合は「**すべて削除**」を押します

## 使用技術

- React 19
- Vite 8
- JavaScript (ES Modules)
- HTML / CSS（バニラCSS）
- localStorage（ブラウザ標準）
- gh-pages（GitHub Pages デプロイ用）

データベースや外部サーバーは使っていません。すべてブラウザ内で完結します。

## 成果の確認方法

### ローカルで動かす場合

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

ターミナルに表示されるURL（通常 `http://localhost:5173`）をブラウザで開いてください。

### 動作確認の手順

1. 各質問に回答を入力する
2. ブラウザを再読み込みしても内容が残っていることを確認する
3. 「送信する」を押し、入力内容が一覧表示されることを確認する
4. 「編集する」を押し、入力画面に戻れることを確認する
5. 「すべて削除」を押し、内容がクリアされることを確認する

### 本番ビルド・プレビュー

```bash
npm run build       # dist/ にビルドされる
npm run preview     # 本番ビルドをローカルでプレビュー
```

### デプロイ手順（参考）

1. GitHub にリポジトリ（例：`hearing-app`）を作成し、`git push` する
2. リポジトリ名と異なる場合は [vite.config.js](vite.config.js) の `base` をリポジトリ名に合わせて変更（例：`base: '/hearing-app/'`）
3. 以下を実行：

```bash
npm run deploy
```

4. GitHubのリポジトリ設定 → Pages で、ブランチを `gh-pages` に設定する

## セキュリティ面で配慮したこと

- **APIキーやパスワードをコードに直書きしていません**（そもそも外部APIを使用していません）
- **データベースを使用していません**。外部サーバーへ通信を行いません
- 入力内容はユーザー本人のブラウザの **localStorage にのみ保存** します
  - 他のユーザーや第三者がデータにアクセスできない設計です
- 外部の解析タグやトラッキングスクリプトは入れていません
- 回答内容は React の `value` バインディングで扱い、`dangerouslySetInnerHTML` などを使用していないため、XSSのリスクを低減しています
- 削除操作時は `window.confirm` で確認ダイアログを表示し、誤削除を防ぎます
